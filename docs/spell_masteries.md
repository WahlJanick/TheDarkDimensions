# Spell-Meisterschaften

Jeder Spell bekommt auf Stufe 5 eine von zwei Spezialisierungen. Erste Auswahl kostenlos; Wechsel im Survival: ein Chronus Infused Ingot. Creative wechselt frei. Im Vanilla-Skilltree den Spell anklicken, dann den gewünschten Seitenzweig. Vorhandene Fortschritte bleiben erhalten.
