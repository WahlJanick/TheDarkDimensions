# Minecraft UI style

Explicit user requirement: every menu added by The Dark Dimensions must retain
Minecraft's original UI look. Apply this to future menus as well as existing ones.

- Prefer Minecraft's actual container textures, GUI sprites, widgets, font and
  tooltips. Reference vanilla resources directly so resource packs also apply.
- Use gray beveled container frames, standard inventory slots and vanilla buttons.
  Do not introduce custom dark-blue panels, gradients, rounded dashboard cards or
  element-colored menu backgrounds.
- Skilltrees should look like Minecraft's advancements UI. The requested XP-green
  or gray skill status borders are allowed; put requirements and details in hover
  tooltips instead of filling the screen with explanatory text.
- Preserve established controls and gameplay when changing menu styling.
